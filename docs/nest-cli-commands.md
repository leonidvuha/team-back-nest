```nest generate module <name_of_module>``` - сгенерирует папку для модуля с названием name_of_module и внутри нее будет файл .module.ts

```nest generate controller <name_of_module>``` - сгенерирует controller, spec - тесты для контроллера

```nest generate service <name_of_module>``` - сгенерирует service, spec - тесты для контроллера
